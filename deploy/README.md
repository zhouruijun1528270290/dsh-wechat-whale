# 小鲸鱼 · 微信机器人

一个跑在自己电脑上的微信聊天机器人：有固定人格、有跨天记忆、有情绪刻度、会发表情包。

**你不需要懂技术。** 这份说明是写给你转交给 AI 的。

---

## 你该怎么做

1. 把这个**文件夹整个**（或 README 加 `AGENTS.md` 两个文件）发给你在用的任意 AI 助手 —— DeepSeek、Claude、ChatGPT 都行。
2. 跟它说一句：**「按 AGENTS.md 帮我装好这个项目，卡住了再问我。」**
3. 它会自己检查环境、改配置、跑命令。中途它只会问你三件事：
   - 你的 DeepSeek API key（去 platform.deepseek.com 申请）
   - 用手机微信扫码（绑机器人）
   - 这个人设要不要改（默认是「小鲸鱼」，一个爱睡觉、爱怼人的鲸鱼妹妹）

装好之后，微信里会多一个联系人，你跟它说话它就会回 —— 冷的时候会怼你，你真有事的它会认真陪。

---

## 会花你什么

| 项目 | 大概 |
|---|---|
| DeepSeek API key | 自己申请，充多少看你自己 |
| 每天的 token | 日常闲聊一天几毛钱量级 |
| 电费 | 电脑得一直开着 |
| 你的时间 | 装的时候 20 分钟左右 |

---

## 装完是什么样

- 微信里多一个联系人，发消息就回，会一条一条地发、会显示「正在输入」
- 它会记得你昨天说过的事、记得你们之间的梗
- 偶尔甩一张表情包过来
- 电脑上有个本地网页（`127.0.0.1:8787`），能看状态、日志、记忆，能改密码、能重启

---

## 出问题了怎么办

**把报错原文整段丢给 AI**，别自己猜。`AGENTS.md` 最后一节有一张「错误 → 含义 → 怎么修」的表，AI 看了基本能自己解决。

最常见的两个：

| 现象 | 原因 |
|---|---|
| 黑窗口一闪就没了 | 启动脚本的换行符不对（必须 Windows 的 CRLF） |
| 提示 profile 启动失败 / JSON 解析错误 | 配置文件被写进了 BOM（文件头三个看不见的字节） |

---

## 你需要自己守的两条

1. **别把 `config.json` 和 `.credentials.yaml` 发到群里** —— 里面有你的 key 和本机路径。
2. **API key 只填在机器人自己的目录里**，不要跟你在 DSH 日常用的那份混在一起。
