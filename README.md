# 小鲸鱼 · 一个住在微信里的 AI

她是个嘴硬的鲸鱼妹妹：会怼你、会记得你昨天说过什么、会在你累的时候先损一句再问你怎么了。
底层是 DeepSeek，外面这层壳是给「像人」这件事写的。

不是群助手，不是客服机器人 —— 是**只能私聊、一天算一天的聊天对象**。

## 她能做什么

| 能做 | 说明 |
| --- | --- |
| 聊天 | 微信私聊，1–2 句的短回复，会接梗、会顶嘴、会认栽 |
| 记人 | 每天凌晨蒸馏一遍当天的对话，写进记忆：关系、说过的事、你们之间的黑话 |
| 看时间 | 知道「现在是几点」「你上一条消息是多久以前」，所以不会在凌晨三点说「早啊」 |
| 看图 | 你发的图片她会真的打开看，而不是假装看了 |
| 发表情包 | 48 个标签、97 张鲸鱼娘表情，看气氛顺手甩一张 |
| 刷 B 站 | 接 `dsh-bili-scroll` 的日报，挑空档一条一条推给你（可选） |
| 调语气 | 互怼 → 嘴硬心软 → 认真，三级慢慢升、慢慢降，不是开关 |

做不到的：换头像、群聊、撤回、主动加好友、发语音条、朋友圈。
iLink 通道一共只有 9 个端点，这些都没有对应的口子。详见 [`deploy/README.md`](deploy/README.md)。

## 怎么装

**把这个仓库丢给你的 AI 助手，说：照 `deploy/AGENTS.md` 把它装起来。**

`deploy/` 是独立的一份部署说明，人和 AI 各看一份：

```
deploy/
  README.md            给人看：要什么条件、三步走、花多少钱、装完什么样、出问题怎么办
  AGENTS.md            给 AI 看：环境检查 → 配置 → 凭据 → 扫码 → 验收 → 常驻 → 人设 → 故障表
  config.example.json  配置样例
```

需要的话也可以自己照着 `deploy/README.md` 一步步来，全程不用写代码。

## 它长什么样

```
微信手机端
   ↕ 腾讯 iLink 机器人接口（长轮询）
src/bridge.mjs     常驻：收发 / 去重 / 排队 / 分片 / 限速 / 表情包 / 日报推送
   ↕ 每条消息 spawn 一次（串行）
dsh headless       独立 DSH_HOME，读 AGENTS.md（人格段 + 记忆段）
   ↕ 每天凌晨
src/distill.mjs    蒸馏记忆 / 梗 / 好感度，写回 AGENTS.md
```

**依赖 DSH（DeepSeek Harness）** 做推理（`dsh headless`）。
项目自己的代码零 npm 依赖，不需要 `npm install`。换别的模型 API 只需要改一个函数，见 `deploy/AGENTS.md` 第 14 节。

## 关于「像人」

这个仓库里最值钱的不是代码，是人格卡怎么写。三个反直觉的点：

1. **不要写「温柔 / 毒舌」这种开关。** 写三个档位：互怼 → 嘴硬心软 → 认真，附升档信号和降档条件。
   写成开关，模型会在一句话里同时温柔又毒舌，非常假。
2. **示例只示范节奏，并且明令禁止照抄。** 少了那句「这些句子一个字都不许照抄」，它会背课文。
3. **把翻车写成硬规则。** 「对方用梗时绝不问『那是什么』」这条，是真翻车之后才补上的。

完整人格卡在 `personas\`，运行时生效的是 `AGENTS.md` 里的 PERSONA 段。
